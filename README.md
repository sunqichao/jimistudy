# 基米英语 JIMI English

面向中文学习者的**纯前端英语学习应用**：六个学段、十三个学习模块，从自然拼读到四六级、职场英语和 AI 术语。没有构建步骤、没有第三方依赖、不需要注册，打开网页就能学。

![build](https://img.shields.io/badge/build-none-success)
![dependencies](https://img.shields.io/badge/dependencies-0-success)
![tests](https://img.shields.io/badge/tests-19%20passed-success)
![license](https://img.shields.io/badge/license-MIT-blue)

- **免安装**：双击 `index.html` 即可运行，也可以用任意静态服务器托管。
- **纯前端**：原生 HTML / CSS / JavaScript，没有框架、没有打包器、没有 npm 依赖。
- **离线可用**：朗读使用浏览器自带的 Speech Synthesis，不加载任何外部音频或字体。
- **进度本地化**：所有学习记录保存在浏览器 `localStorage`，不上传服务器。
- **数据即内容**：新增词条、题目、专题只需要改 `data/*.js`，跑一遍测试即可验证格式。

## 快速开始

```bash
git clone https://github.com/sunqichao/jimistudy.git
cd jimistudy
```

任选一种方式打开：

```bash
# 方式一：直接打开
open index.html            # macOS
# start index.html         # Windows
# xdg-open index.html      # Linux

# 方式二：本地静态服务器（推荐，语音识别需要安全上下文）
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

首次打开会先让你选择学习阶段，之后可在顶栏随时切换。每个学段的内容和进度彼此独立，星星与连续学习天数为全学段共享。

## 学习机制

- **每日目标**：每天完成 5 次有效学习（答对题、完成任务）即达成，首页有进度条。
- **连续学习天数**：当天有学习即 +1，隔一天没学则中断。
- **星星**：首次完成一个条目奖励 1 颗，全局累计。
- **学段完成度**：按各模块已学条数计算；错题本这类不依赖录入内容的模块不计入。
- **今日推荐**：按“单词 → 拼读 / 词根 → 句子 → 听写 → 错题 → 动画 → 阅读 → 语法 → 口语 → 写作 → 专题 → 考试”的顺序，挑出当前最该做的一件事。
- **间隔复习**：答错的单词立即进入复习队列，之后按 1 / 3 / 7 / 14 天递增，只有到期的复习才推进间隔，避免连点刷进度。
- **单词分组**：单词达到 31 个及以上时，按每 20 个一组显示分组栏和“跳到下一个没学的”按钮。

尚未开放的模块已作为占位出现在侧栏和首页，点进去可以看到计划内容：

| 学段 | 占位模块 |
| --- | --- |
| 小学 | `songs` 英文儿歌 |
| 职场 | `templates` 邮件与会议模板库、`interview` 英文面试 |
| AI | `prompt-library` 提示词模板库、`paper-reading` 论文与文档阅读 |

各模块页面底部还会显示来自学段 `roadmap` 的“接下来会补充”清单。

```text
├─ data/
│  ├─ registry.js            全局注册表 window.JIMI（levels / modules / rootsData）
│  ├─ primary.js             小学内容 + 学段配置
│  ├─ middle.js              中学（初中）
│  ├─ high.js                高中

│  ├─ work.js                职场（通用 / 程序员 / 产品经理）

│  ├─ words-extra.js         小学 / 中学 / 高中 / 大学的补充单词（并入各学段 words 末尾）
│  ├─ roots-affixes.js       前缀、后缀（全学段共用）

│  ├─ app.js                 状态、路由、首页 / 侧栏 / 学段选择、事件分发
│  ├─ core/                  7 个基础工具
│  │  ├─ utils.js            HTML 转义、哈希、固定种子洗牌、选项生成
│  │  ├─ ui.js               toast 与鼓励动画
│  │  ├─ storage.js          进度读写、脏数据清洗、v1 迁移
│  │  ├─ streak.js           每日目标与连续天数
│  │  ├─ speech.js           语音合成与音色选择
│  │  ├─ quiz.js             选择题渲染与判分
│  │  └─ recognition.js      语音识别封装与文本相似度
│  └─ modules/              13 个学习模块，接口统一
├─ tests/

```

分层很直接：`data/*.js` 只负责内容与学段配置，`js/modules/*.js` 只负责交互与渲染，`js/app.js` 负责页面外框与事件分发。模块通过 `JIMI.registerModule({ id, unit, defaults, initUI, render, summary, recommend, actions })` 注册，`render(ctx)` 只返回 `{ step, body }`，外框、进度条、路线图提示由 `app.js` 统一生成。

## 开发指南

### 补充内容

1. 在对应学段文件的 `xxxContent` 里追加条目，字段可参考同文件已有条目；`id` 在同一学段内必须唯一。
2. 运行 `node --test tests/data.test.js` 校验：字段是否齐全、答案下标是否越界、释义是否重复、`quizWord` 是否存在，**写作范文必须能通过自己的自动检查**等。
3. 如果新增内容命中“接下来会补充”的清单，同步删掉学段 `roadmap` 里对应的条目。

常用字段速查：

- **单词**：`word`、`ipa`、`meaning`、`example`（必填），`pos`、`exampleZh`、`emoji`、`color`（可选）。
- **批量补词**：在 `data/words-extra.js` 里调用 `JIMI.extendWords('middle', [[word, ipa, pos, meaning, emoji, example, exampleZh], ...])`，颜色自动轮换；同一学段内单词和释义都不能重复。
- **句子**：`id`、`sentence`、`translation`（必填），`hint`、`emoji`、`extraWords`、`words`（自定义分词）。
- **阅读**：`passage: [{ en, zh }]`，`questions: [{ q, options, answer, explain }]`，可选 `keywords: [{ word, meaning }]`。
- **语法**：`points: [{ rule, note?, examples: [{ en, zh }] }]`，`exercises` 与阅读题格式相同。
- **自然拼读**：`id`、`letter`、`name`、`sound`、`tip`、`words: [{ word, meaning, emoji }]`（第一个例词必须以该字母开头）。
- **写作**：`id`、`title`、`subtitle`、`emoji`、`type`、`prompt`、`promptZh`、`minWords`、`phrases: [{ en, zh }]`、`sample`，可选 `tips`、`color`。
- **口语对话**：`id`、`title`、`subtitle`、`emoji`、`roles: ['角色A', '角色B']`、`lines: [{ who: 0 或 1, en, zh }]`（至少 4 句，两个角色都要有台词）。
- **模拟考试**：`id`、`title`、`subtitle`、`emoji`、`type`、`minutes`、`questions`（格式同阅读题），可选 `passage`（完形填空用 `(1)`、`(2)` 标出空格，题号与空格一一对应）。
- **词缀词根**（`data/roots-*.js`，用 `JIMI.defineRoots([...])`）：每行 `[id, 类型(prefix/suffix/root), tier(1 初中 / 2 高中 / 3 大学及职场), 显示形式, 变体数组, 来源, 含义, 记忆提示, [[词, 释义, 拆分], …]]`。拆分用 `|` 分隔，词缀带连字符，如 `'pre-|view'`、`'help|-ful'`；**各段去掉连字符后拼起来必须等于原词**，且至少有一段是该词缀 / 词根的变体。每个单元至少 5 个例词。三道小题由代码按固定种子自动生成，第 3 题的干扰项会自动避开“看起来也含有该词缀”的词。

### 新增模块

1. 新建 `js/modules/xxx.js`，调用 `JIMI.registerModule(...)`，并在 `index.html` 里加一行脚本。
2. 按钮用 `data-action="模块id:动作"`；输入框用 `data-input="模块id:动作"`，回车用 `data-submit="模块id:动作"`。
3. 答对 / 完成任务时调用 `ctx.bump()` 计入每日目标；首次完成时 `ctx.markDone(id)` + `ctx.awardStar()`。
4. 内容可由其他数据推导时实现 `contentFrom(level)`（参考 `listening.js`），不必再录一份。
5. 不依赖录入内容的模块（如错题本）设置 `standalone: true`，它将始终可用，也不计入学段完成度。
6. 需要按条件上锁时实现 `locked(ctx)`，返回 `{ message, hint, navLabel, redirect }`（参考 `sentences.js`）。
7. 需要收集错题时调用 `ctx.recordMistake(模块id, 题组id, 题号)` / `ctx.clearMistake(...)`；题号必须稳定，所以自动出题使用固定种子。

### 新增学段

新建 `data/xxx.js` 并调用 `JIMI.registerLevel(...)`，然后在这三处各加一项：

1. `data/registry.js` 的 `levelOrder`（决定首页卡片顺序）
2. `index.html` 的脚本列表（测试也依赖这个顺序加载）
3. `styles.css` 中的学段主题变量：`#app[data-level="xxx"]` 与 `.level-xxx` 卡片底色

可参考 `data/work.js`。

## 设计说明

- **为什么不用框架**：这是一个内容驱动的学习工具，页面结构简单但状态较多。原生 DOM + 统一的 `render(ctx)` 已经够用，换来的是零依赖、零构建和极低的维护成本。
- **数据与逻辑分离**：所有词条、题目、对话都是纯数据，考试题号、选项顺序由固定种子生成——同一道题每次渲染顺序一致，错题记录才能稳定对应。
- **存储要能自愈**：读取进度时会逐字段校验，丢弃结构非法的记录；错题最多保留 200 条、每篇写作草稿最多 5000 字符，坏数据不会导致页面白屏。
- **向后兼容**：旧版只有一个年级的数据（`xiaoxue-en-progress-v1`），首次打开会自动迁移到小学学段，学习记录不丢。
- **语音只用浏览器能力**：朗读走本地 Speech Synthesis，优先美式音色，各学段语速不同（小学 0.78 / 中学 0.85 / 高中 0.9 / 大学、职场、AI 0.95）。语音识别可选，不上传、不保存任何录音。
- **界面适配**：1050px 以下收窄侧栏与留白，760px 以下隐藏侧栏改为底部导航，并尊重系统的“减少动态效果”设置。

## 浏览器支持

| 功能 | Chrome / Edge | Safari | Firefox |
| --- | :-: | :-: | :-: |
| 全部学习模块 | ✓ | ✓ | ✓ |
| 语音朗读 | ✓ | ✓ | ✓（依赖系统音色） |
